# ☕ Portfólio | Alcyenny Silva

Olá! Sou Alcyenny Silva, estudante de **Sistemas de Informação** e desenvolvedora Front-end em formação.

Este repositório contém meu portfólio pessoal, criado para apresentar um pouco da minha trajetória na tecnologia, meus conhecimentos e projetos desenvolvidos durante meu aprendizado.

## ✨ Sobre o projeto

O portfólio foi desenvolvido com uma identidade visual inspirada em tons de café, buscando transmitir personalidade, simplicidade e elegância.

O site possui páginas dedicadas à minha apresentação, trajetória, projetos e informações de contato.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização, identidade visual e responsividade.
- **Git e GitHub:** versionamento e hospedagem do código.

## 📂 Estrutura do projeto

```text
meu-portfolio/
```

## 🚀 Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/alcyenny-silva/meu-portfolio.git
   ```

2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` no navegador.

## 🎯 Objetivo

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento Front-end e representa um espaço para praticar, experimentar e evoluir na construção de interfaces web.
